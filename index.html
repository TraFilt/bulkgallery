FAQ

Frequently asked questions

Is BulkGallery really free?

Yes — it's free to use with no limits on the number of designs you generate.

Does it save or upload my data anywhere?

No. Your template image and data are processed entirely inside your browser and are never sent to a server.

Can I use it on my phone?

Yes — the tool works on mobile, with tap-to-place fields and on-screen controls instead of dragging.

Do I need to know Excel or CSV formatting?

No — you can type your data directly into a simple table inside the tool, no spreadsheet knowledge required.

What file formats can I download?

Choose a ZIP file of individual PNG images, or one combined multi-page PDF.

1. Open a spreadsheet
Open Excel, Google Sheets, or Numbers and create a new sheet.

The very first row must contain your field names.
3
3. One row per design
Every row after the header becomes one generated design.
4
4. Export as CSV
Use File → Download → CSV.

A few tips
  • If a value contains a comma, wrap it in double quotes.
  • Keep column names short and clear.
  • Save with UTF-8 encoding if your data includes Arabic text.
  • Empty rows are ignored automatically.
